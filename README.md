# Vertical Multi-AI — Tester Pilot

A test version of the Windows app. Use made-up information only. Do not enter passwords, private documents, or other sensitive information into your test content.

## Download and install

1. Open **Releases** on this GitHub page.
2. Download the latest Windows installer (`.exe`). If there is no installer, the download is not ready yet.
3. Close the app if you already have it open.
4. Run the installer. The default options are fine.
5. Open **Vertical Multi-AI Tester Pilot** from your desktop or Start menu.

**Windows warning:** This pilot has no verified publisher signature. Continue only if you trust this repository and downloaded the installer from its Releases page. Do not disable Windows security.

## First use

1. Create an account, or sign in to your existing account.
2. For a new account, open the verification email. Check your Spam folder if necessary.
3. Open or create a Workspace.
4. Open or create a Container.
5. Register this desktop if the app asks. Give each device a different name.
6. Open a document and try the available controls.

For two devices, install the app on both. Use the same account to access your own work. To work with another person, invite their separate account to your Workspace and give them Container access.

## Important

- Keep an internet connection. The pilot server is not always online.
- If the app cannot connect, ask the person who invited you whether the server is online.
- Updates are manual. Download the new installer, close the app, and install it over the existing version.
- Do not uninstall the app or delete its data just to update it.
- Documents and features depend on your access and the Container's workflow release.
- Pilot data can be lost. Do not use this app as your only copy of important work.

## Report a problem

Tell the person who invited you:

- What you tried.
- What you expected.
- What happened instead.
- The approximate time.
- A screenshot, if useful.

Remove private information from screenshots. Never share passwords, verification links, or account recovery links.
